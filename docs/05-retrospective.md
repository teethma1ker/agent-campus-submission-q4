# 05 复盘

## 实际用时

约 2.5 小时（数据与规则 30 分钟、工具与循环 60 分钟、调试压缩与测试 45 分钟、真实模型与文档 45 分钟）。

## 最难的问题

1. **时长闭环**：首稿、压缩、保存必须共用同一套估算，且压缩要真实减字数而不是改声明。
2. **事实追溯的边界**：数字容易查，非数字表述（“简洁设计”）才是真实模型最常犯的编造，需要属性词表补足。
3. **核对口径**：模型在估算之后可能微调脚本，保存时重算的时长才是最终真值，核对必须以它为准。

## 学习收获

- 创作类 Agent 的“可核查性”来自工具：时长、规则、事实都由工具裁决，模型只负责写作与选择；
- 编造拦截要分层：数字、属性词、效果百分比各有一套规则，“看起来合理”不构成依据；
- 真实模型的输出需要和系统防线共同设计，防线要能拦住模型的最优看似解。
