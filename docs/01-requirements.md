# 01 需求说明

## 用户

内容创作者/运营：给出主题、受众、平台、目标时长与风格，需要一版可编辑脚本（标题、分镜、旁白/字幕），
且必须满足平台时长限制、符合品牌规则、不编造产品事实。

## 目标

产出可核查的脚本：每个分镜有素材来源 ID、每个数字可追溯到素材事实、总时长由工具估算、
超时长时真实压缩重估；无法满足时明确说明原因。

## 输入

- 主题、受众、平台、目标时长、风格；
- 合成素材（P01-P06，含事实 facts 与质量标签）；
- 品牌规则（禁词、禁用素材、促销免责声明、平台时长上下限、±10% 容差、事实追溯规则）。

## 交付结果

标题、分镜（画面/旁白/字幕/素材 ID）、逐分镜时长与总时长、素材来源、规则检查结果、风险、任务状态与保存结果。

## 范围

做的：素材检索、时长估算、规则检查（含数字与产品属性词的 facts 追溯）、保存双检、超时长压缩重估、编造拦截。

不做：真实视频生成/发布、真实素材库、多轮创意迭代、界面。

## 成功标准

1. 正常生成：分镜/旁白/字幕/素材/总时长齐全，时长在目标 ±10% 与平台范围内；
2. 缺关键信息：说明缺什么，不硬编脚本；
3. 无素材：不得挪用无关素材硬凑，明确说明无可用素材；
4. 工具失败：重试一次，仍失败说明无法确认时长；
5. 超时长：压缩重估（参考实例 38→28）；不可满足（目标短于平台下限）时明确说明；
6. 事实可追溯：编造的百分比/产品属性被规则拦截，修正后才能保存。
